# Privacy Policy

**Production Dashboard UI/UX Skill** is an instruction-only skill and plugin package maintained by Pooya Hayati.

Last updated: 2026-09-19

## Data collection

The package itself does not operate a remote server, create user accounts, collect analytics, store conversations, or transmit user data to the maintainer.

The skill provides instructions that ChatGPT or Codex can apply inside the user's current environment. Any files, repositories, connected tools, or project data accessed during execution are governed by the user's ChatGPT/Codex environment, enabled tools, permissions, and the policies of those services.

## External services

This package does not require an external MCP server and does not require a third-party account to perform its core workflow.

If a user independently enables other tools, MCP servers, repositories, or services while using the skill, those services have their own privacy practices and terms.

## Local project files

The skill may instruct the agent to inspect or modify frontend project files when the user asks for implementation work. It may also create a local `design-profile.md` in the user's project to preserve approved design decisions.

The maintainer does not receive those files or their contents through this package.

## Sensitive information

Users should not include credentials, API keys, passwords, private tokens, or unnecessary personal data in public bug reports or contribution examples.

## Changes

Material changes to this policy will be documented in the repository history.

## Contact

For privacy questions, open a minimal GitHub issue that does not contain sensitive information and request a private contact channel:

https://github.com/pooyahayati/production-dashboard-ui-ux-skill/issues
